colophon

how and why this page is like this.
────────────────────────────────────────────────────────────

Written in a text editor. No build step. No framework. No package.json. The whole site is four files and one of them is the button.

The layout is a <table>. This is not irony. It is the correct tool for a two-column document that will never be responsive, and I would like the record to show that it has never once broken.

~ Digital Nostalgia ~

First Website Memory - 2018
I still remember the excitement of publishing my first HTML page! It was just a pink background with Comic Sans text saying "Welcome to Berry's Page!" but I felt like I'd created magic. Seven years later and that feeling never gets old.
Discovery of Neocities - 2020
Finding Neocities was like discovering a secret garden of creativity. Suddenly I wasn't alone in wanting websites to be personal and expressive again. The community there taught me so much about indie web culture.
Learning JavaScript - 2021
The moment when I made my first interactive element work felt like casting a spell! A simple button that changed colors on click, but it opened up a whole world of possibilities. Interactive design became my passion.
Building My First Web Ring - 2022
Connected with amazing artists and developers through shared aesthetics and values. The early web spirit of linking to friends and supporting each other's creativity is something we should never lose. ♡

# Licensing

GitHub detected no SPDX license in the source repositories at migration time. This archive therefore does not impose a blanket license on template code, images, fonts, audio, or fandom material.

- Preserve embedded credits and notices.
- Review remote and bundled assets before reuse or redistribution.
- Treat `license_status` in each `template.json` as the authoritative migration-time status.
- New collection metadata and provenance records document migration; they do not relicense source content.
